# Space Dashboard

A customizable, space-themed browser dashboard powered by NASA imagery — built for Hack Club Stardance.

**Live demo:** https://qadir-eng.github.io/space-dashboard/

## Features

- NASA Astronomy Picture of the Day as the live background

- Loading screen while the NASA background is being fetched

- Live digital clock that updates every second

- Customizable clock with:
  - Multiple clock fonts
  - Multiple clock colors
  - Day/Night color mode

- Quote of the Day with randomly selected space/inspirational quotes

- Google search bar with a glass-style design

- Quick shortcuts for YouTube, Gmail, Stardance, and Hackatime

- **To-Do panel** — a draggable glass-style task panel with 4 task inputs

- **Background customizer** — switch between:
  - NASA Daily background
  - 5 curated space wallpapers
  - Solid-color backgrounds

- **Space Menu** — a sliding hamburger sidebar for accessing dashboard controls without cluttering the main screen

- **Clock Style selector** — cycle through Digital Ops, Audiowide, Michroma, Bruno Ace, and Oxanium

- Glassmorphism UI with translucent panels, background blur, and a space-inspired interface

## Built with

HTML, CSS, and JavaScript with Vite.

NASA APOD API for live space imagery and Google Fonts for the dashboard typography.
